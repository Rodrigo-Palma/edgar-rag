# NNNN. Title in the imperative, naming the decision

- Status: Proposed | Accepted | Superseded by [NNNN](NNNN-title.md)
- Date: YYYY-MM-DD

## Context

The forces at play: what is true about the code, the data or the tools that
makes a decision necessary. State measured facts with the number, the
conditions it was measured under, and where it lives (a file path, a test, a
commit). Say what is not known.

## Decision

What we do, in one short paragraph, written so it can be checked against the
code. Name the module, type or flag that carries it.

## Consequences

What becomes easier, what becomes harder, and what this does not cover. Include
the cost and the conditions under which the decision should be revisited.

## Enforced by

Tests that fail if the decision is violated, as relative links. A decision with
no test here is a statement of intent, and the ADR should say so.
